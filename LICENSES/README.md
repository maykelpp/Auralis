# LGPL-3.0-only compliance

The scaffold is intended to use LGPL-3.0-only. Before distribution, include the complete canonical license text.

Before incorporating Mornye code:
1. Verify the exact upstream revision and per-file notices.
2. Preserve copyright and license headers.
3. Record source paths, revisions and modifications in THIRD_PARTY_NOTICES.md.
4. Provide corresponding source and comply with LGPL-3.0 relinking/replacement requirements applicable to the distribution.
5. Audit every dependency separately; Mornye's license does not relicense its dependencies.

This checklist is not legal advice.
